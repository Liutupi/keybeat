# 键拍 KEYBEAT

跟着节拍敲单词的英语打字游戏，纯网页，打开 `index.html` 就能玩。

## 玩法

- **节奏**：一章 20 个词，按键踩在拍点上得分更高，超时或敲错会断连击。
- **竞速**：限时 45 秒，测 WPM。
- **听写**：只给发音和中文释义，凭记忆拼写。
- **拼词**：听发音、看中文，点字母块把词拼出来。
- **NABO 跑酷**：字母障碍迎面而来，在撞上之前打出来；三条命，越跑越快。角色素材说明见 `docs/nabo-assets.md`。
- **每日挑战**：每天从当前词库固定抽 20 个。

电脑上用实体键盘；手机和平板上自动显示屏幕键盘，拼词模式可以单手玩。

选择 NABO 跑酷后可在首页观看宣传片；游戏结束时会显示对应的通关或失败短片。跑道上使用 NABO 的跑步、跳跃和碰撞形象；动作帧仍在完善。视频播放需要网络，手机实际体验有待验收。

音乐和音效由浏览器实时合成；连击越高，加入的乐器层越多。

小学词表按教材附录的单元词汇整理：三上、三下、四上、四下、五上、六上为 2024 起的新版，五下、六下为 2014 旧版（旧版两册没有音标）。初中单词基于人教教材词表，排除了本项目小学词表和参考课标二级词表中的词及常见变体、教材人物姓名，修正了部分拼写和释义。它是初中学习补充词库，并非完整课标词表；不同教材的学段安排可能有所不同。短语和其他词表主要做格式清洗，未逐条校对。

初中词库的五册（七上、七下、八上、八下、九上）按各册课本后的 Vocabulary 词汇表转录，册内按课本页码排序，每 20 个一章，八上的 `3-D` 因含数字未收录；原先整理的初中词中教材以外的 414 个放在“补充”。转录的原始表格在 `tools/pep-junior-vocab.tsv`。

初中词库调整后章节内容会重新排列；原有学习记录不会被清除，但已通过章节的数字进度不代表新章节中的词均已学过。建议先在“我的”中导出备份。

## 学习记录

等级和经验、每日目标与连续达标、间隔复习（今日复习）、成就、最近记录，都保存在当前浏览器的本地存储里，没有服务器。换设备请在"我的"页面导出备份再导入。

## 发音

联网时优先播放有道词典的单词录音（会把当前单词发给有道的服务器），加载失败时退回浏览器自带的语音合成。

## 重新生成词库

```sh
python3 tools/build_data.py <qwerty-learner/public/dicts> data <pep-vocab-3-6-by-unit.csv>
```
